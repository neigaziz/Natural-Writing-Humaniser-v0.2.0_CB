# Responsibility Model

| Component | Primary responsibility |
|---|---|
| Model | Interpret, classify, reason, synthesize, explain |
| Trusted instructions | Establish global and non-negotiable behavior |
| User request | Set current objective and authorization |
| Skill | Package reusable methodology, routing, and decisions |
| Tool | Perform one narrow external or deterministic action |
| MCP | Standardize access to external tools/resources |
| API | Expose external systems programmatically |
| RAG | Retrieve relevant evidence with provenance |
| Files | Supply task/domain data |
| Code | Calculate, transform, sort, validate, and reproduce |
| Memory | Retain approved useful state |
| Agent | Orchestrate workflows, tools, and checks |
| Evaluation | Measure behavior and regressions |
| Observability | Explain routing, calls, outcomes, cost, latency, versions |
| Human approval | Govern consequential or ambiguous decisions |

Avoid assigning the same authority to multiple layers. Prompts are not substitutes for access control, schema validation, deterministic calculation, retries, or audit logs.
