# Autonomy Framework

| Level | Behavior | Controls |
|---|---|---|
| 1 Advisory | Recommendations only | User executes |
| 2 Tool-using | Narrow approved calls | Confirmation for meaningful changes |
| 3 Workflow | Multi-step creation and validation | Checkpoints; approval for consequential actions |
| 4 Autonomous | Complex independent execution | Strong monitoring, recovery, permissions, evaluation |
| 5 Multi-agent | Orchestrated specialists | Handoffs, shared-state controls, independent review |

Choose the lowest level satisfying the need. This Skill defaults to Level 3: it may create, edit, test, validate, and package inside a sandbox or approved workspace. It must stop before installation, deployment, external communication, production change, destructive action, financial transaction, or permission expansion.
