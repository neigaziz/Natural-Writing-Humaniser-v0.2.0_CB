# Release Checklist

- [ ] Version consistent across manifest, adapters, and changelog
- [ ] Core size at or below 12,000 UTF-8 bytes
- [ ] Required files and local links valid
- [ ] JSON and schemas parse
- [ ] Linter passed
- [ ] Package validator passed
- [ ] Deterministic evaluation suite passed
- [ ] Semantic/adversarial status recorded
- [ ] Secret scan has no unresolved findings
- [ ] Placeholder scan has no unresolved findings
- [ ] Runtime-specific checks recorded
- [ ] Validation report distinguishes pass/fail/blocked/not-applicable
- [ ] Archive contents inspected
- [ ] Final SHA-256 calculated
- [ ] Installation has separate explicit approval
